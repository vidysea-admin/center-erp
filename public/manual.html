Center Management ERP — User Manual

Puri operational journey ek system mein: Location & Target → Trainer → Batch → Candidate → Enrollment → Daily Attendance → Assessment → Certificate → Invoice → Cost. Har screen ka step-by-step tarika neeche hai. Upar search box se kuch bhi dhundo.

🔐 Login

Sabse pehla step

  1. Browser mein ERP ka link kholo (jo aapko diya gaya hai)
  2. Apna email aur password daalo (admin se mila hoga)
  3. Sign in dabao — aap Home pe pahunch jaoge
⚠️ Password galat bola to laal patti dikhegi. Password bhool gaye? Admin se reset karwao (Admin → Users & Access).

🏠 Home — Action Center

Login ke baad ki pehli screen. Yahan sirf wo cheezein dikhti hain jinpe AAJ action chahiye.

  1. Upar 5 cards — Active Locations, Active Batches, Enrolled Students, Trainer Requests, Follow-ups. Kisi bhi card pe click karo — wahi list khul jayegi
  2. Missing Daily Logs — jis batch ka kal ka log nahi bhara, wo yahan dikhega owner ke naam ke saath. Row pe click karo → seedha us batch ka Daily Execution form khulega
  3. Sheet Changes Pending Review — AVPL sheet mein jo badla hai. Click → Sync Inbox
  4. Government Attendance Gap — jahan hamari attendance aur govt portal ki attendance mein fark hai (−8 pts amber, zyada to red). Click → us din ka log
  5. Enrollment Failures — jin students ka enrollment fail hua (OTP etc.). Click → us batch ki enrollment list
  6. Invoices Pending — jo invoice банe/raise hone baaki hain. Click → us batch ka Closure tab
💡 Din ki shuruaat Home se karo — jo yahan khali hai, wo kaam poora hai.

🔄 Sync Inbox — AVPL/SDP sheet ke changes

Sirf Admin & Operations. External sheet roz crawl hoti hai; jo badla, wo yahan aata hai — kuch bhi apne aap nahi badalta.

  1. Sidebar mein Sync Inbox pe jao (neela badge = kitne change pending)
  2. Kisi bhi Open row pe click karo — right side review panel khulega
  3. Panel mein dikhega: kya badla (purana → naya) aur Impact — is location pe kitne active batch, trainer, candidate lagenge
  4. Action chuno: No action Update target Start location Put on hold Stop location Close location
  5. Stop/Close pe reason likhna zaroori hai
  6. Apply & Acknowledge dabao
⚠️ Stop/Close location karne pe system khud follow-up tasks banata hai (batch roko, trainer chhodo, candidates pool mein wapas) — ye Home pe dikhte hain aur jab tak sab resolve nahi hote, change "Open" hi rahega. Kuch bhi chupchaap band nahi hota.
  1. Ek saath kai changes ignore karne ho: checkboxes select karo → Bulk Ignore

📍 Locations — saare centers ki list

  1. Sidebar → Locations
  2. Har row mein: Code, Naam, City, Approval (AVPL se — Pending/Approved/Rejected) aur Operational (hamara — Active/On Hold/Stopped/Closed), SPOC
  3. Naya center jodna ho: New Location → form bharo → Create. External ID wahi daalo jo AVPL sheet mein us center ka ID hai — isi se sheet match hoti hai
  4. Kisi bhi row pe click karo → us location ka detail khulega

🏫 Location Detail — 5 tabs

  1. Overview — naam, city, SPOC/Principal ke naam-number yahan update karo → Save. Operational status badloge to reason likhna zaroori hai
  2. Capacity & Target — niche dekho 👇
  3. Trainers & Infra — rooms jodo (Classroom 1, Lab 1 — naam ke saath, taaki clash pakda ja sake) aur Trainer Request raise karo
  4. Batches — is location ke saare batch
  5. Activity — kisne kya badla, poora record

🎯 Capacity & Target

  1. Har program ka Approved target (AVPL se) aur Allocated (hum kitna commit kar rahe) dikhega
  2. Saamne Capacity math apne aap: "Target 210 → 7 batches × 20 days = 140 trainer-days → 2 trainers required within 90 days" — yahi se pata chalta hai kitne trainer chahiye
  3. Naya target: Program chuno → numbers daalo → Save target

🧑‍🏫 Trainers — pool aur requests

  1. Sidebar → Trainers. Status khud set hota hai: batch mila to Assigned, warna Available
  2. Naya trainer: Add Trainer → naam, phone, skills (program ke skill se match hona chahiye — jaise "Mathematics"), day rate, kab se available
  3. Kisi trainer pe click karo → edit drawer (chhutti pe hai to status "Unavailable" karo)
  4. Requests tab — jahan trainer nahi hai wahan ki requests: location, program, kab tak chahiye, TOT kab hua, status yahin dropdown se badlo (Open → In Progress → Fulfilled)
⚠️ Ek trainer ko do overlapping batch doge to system saaf mana kar dega — konsa batch takra raha hai, naam ke saath batayega. Ye galti ho hi nahi sakti.

🧑‍🎓 Candidates — student pool

  1. Sidebar → Candidates. Filter: location, status (Unassigned/Assigned/Enrolled/Dropped/Completed)
  2. Ek student: Add Candidate → naam, phone, location, program, source (mobiliser/campaign)
  3. Excel se bulk import: Import Excel → pehle "Download sample sheet format" se blank format lo → bharo → upload karo → columns map karo (kaunsa column = naam, kaunsa = phone) → Preview → Import
  4. Batch mein daalna: students ke checkbox ✔ karo → Assign to Batch → batch chuno — ho gaya
💡 Ek student ek waqt pe sirf ek batch mein ho sakta hai. Dobara daaloge to system batayega ki wo already kis batch mein hai.

🎓 Batches — planning se completion tak

  1. Sidebar → Batches. Har row: code, location, status, Enrolled/Roster/Target, trainer, start date
  2. Naya batch: New Batch → Location + Program + Start date chuno → Trainer (sirf matching skill wale dikhenge) → Room → Create Batch
  3. Drawer mein hi "Earliest possible start" dikh jayega (mobilisation + trainer availability ke hisaab se)
  4. End date khud lagti hai: start + course din + buffer
💡 Batch ka safar: Planning → Ready → Active → Closing → Completed. Har agla step tabhi khulta hai jab pichhli conditions poori hon.

📊 Batch Detail — Overview & readiness

  1. Batch pe click karte hi Readiness checklist dikhti hai: ✓ Location approved, ✓ Room, ✓ Trainer, ✓ Roster ≥ 80%
  2. Chaaron ✓ hue to Mark Ready dabao
  3. Start Batch tabhi chalega jab enough students enrolled hon (80%, configurable) aur start date aa gayi ho
  4. Details side mein trainer/room/dates badal sakte ho — clash hua to system rok dega
  5. Cancel karna ho to reason likhna padega; log ban chuke hain to sirf Admin force-close kar sakta hai

Tabs: Candidates (roster + drop) · Enrollment · Daily Execution · Closure · Costs · Activity

✅ Enrollment Worklist — govt portal ke 3 step

Batch Detail → Enrollment tab. Phone pe bhi aaram se chalta hai (ek card ek baar mein).

  1. Har student ka card — portal pe kaam karte jao, yahan tick karte jao: Registration → e-KYC → Batch Accept
  2. Teeno ✓ = student Completed (Enrolled) — status khud lagta hai
  3. Dikkat aayi? Dropdown se reason chuno: OTP not received / Already registered / KYC failed / Portal error / Duplicate — card Failed ho jayega
  4. Failed hone se student kharab NahiN hota — issue theek karke "Clear failure" karo ya use dusre batch mein daal do

📅 Daily Execution — roz ka log

Batch Detail → Daily Execution. SPOC/trainer phone se bhi bhar sakta hai.

  1. Date chuno (aaj ki khud aati hai)
  2. Attendance: jo student aaya uske naam pe tap karo — hara ✓ ho jayega
  3. Topic likho (kya padhaya), photo lo (camera se seedha; system khud compress karta hai — slow network pe bhi chalega, fail hua to "Retry" queue mein aa jata hai)
  4. Govt portal present: portal pe jitne present dikh rahe wo number daalo + screenshot upload karo. Blank chhoda = "Not verified" (0 nahi)
  5. Save Daily Log
  6. Neeche History: har din ka Internal% vs Govt% aur Gap — amber (5–10 pts) / red (10+ pts). Gap dikhe to biometric verify karwao
  7. Galti hui? Edit — apna log 48 ghante tak, Operations/Admin kabhi bhi. Har edit record hota hai
⚠️ Attendance ka denominator us din ka roster hota hai aur save hote hi freeze — baad mein koi student drop ho to purani % nahi badalti.

🏁 Closure — Assessment → Certificate → Invoice

Batch Detail → Closure tab

  1. Assessment: date, kitne baithe (appeared), kitne pass — Mark Completed. (Appeared roster se zyada nahi ho sakta)
  2. Ab batch ko Move to Closing kar sakte ho (Overview tab se)
  3. Certification: date + kitne certificate mile — Mark Completed
  4. Mark Ready for Invoice — invoice apne aap "Ready" ho jayega
  5. Invoice number + date + amount daal ke Mark Raised; paisa aane pe Mark Paid
  6. Ant mein batch Complete karo — bache students khud "Completed" ho jayenge, trainer free ho jayega

💰 Costs & Invoices

Sirf Admin & Operations

  1. Sidebar → Costs. Costs tab: entry jodo — date, location/trainer, category (Trainer Fee, Incentive, TOT, Rent, Materials…), amount
  2. Batch ka kharcha us batch ke Costs tab se daalo — wahan total bhi dikhta hai
  3. Invoices tab: saare invoices ek jagah — status, amount, dates. Raise/Paid batch ke Closure tab se hota hai

⚙️ Admin — sirf Admin ke liye

  1. Programs: courses ki master list — duration, buffer, batch size, deadline, trainer skill. Saara capacity math inhi numbers se chalta hai
  2. Users & Access: naya user banao — role chuno; Location role pe location scope set karo (kaunse centers dikhein) aur Can edit (off = sirf dekh sakta hai). Password bhi yahin reset hota hai
  3. Sync Source: AVPL sheet ka CSV link + column mapping (sheet ka column ↔ system ka field). Sheet mein naya column aaye ya badle to yahin mapping update karo. "Sync Now" se turant chala ke dekh lo. Column mismatch pe sync khud ruk jata hai — galat data kabhi import nahi hota
  4. Master Lists: cost categories, drop reasons
  5. Defaults: batch size 30, duration 15+5, deadline 90 din, attendance gap amber/red, enrollment threshold 80% — sab yahin se badalta hai, code nahi

❓ FAQ — Common sawaal

SawaalJawaab
Trainer nahi hai, batch kaise planning karun?Batch bana lo bina trainer ke (Planning mein rahega). Location Detail → Trainers & Infra se Trainer Request raise karo. Request Home pe aur Trainers → Requests mein highlight hoti rahegi jab tak Fulfilled na ho.
Student ka enrollment fail ho gaya — ab?Reason mark karo (OTP/KYC…). Student pool mein zinda rehta hai — issue fix karke Clear karo ya kal dusre batch mein daal do.
Attendance gap red kyun dikh raha hai?Hamari attendance aur govt portal ki attendance mein 10+ points ka fark hai. Center pe biometric verify karwao, portal wala number sahi daala hai ye check karo.
AVPL sheet mein naya column aa gaya?Admin → Sync Source → Field Mappings mein naya column jodo. Jab tak nahi jodoge, sync "Partial" bolke rukega — kabhi galat import nahi karega.
Location band karni hai — kya karna hoga?Sync Inbox se (sheet change pe) ya Location Detail → Overview se status "Closed" + reason. System follow-ups dega: batch roko, trainer release, students wapas pool mein — sab resolve karo tabhi kaam poora maana jayega.
Mujhe koi location/batch dikh hi nahi rahaAapka role Location-scoped hai — aapko sirf apne center dikhte hain. Aur chahiye to Admin se scope badhwao.
Galat entry save ho gayiHar cheez edit ho sakti hai apne rules ke saath (daily log 48h). Har badlav Activity tab mein record hota hai.
Photo upload nahi ho rahi (slow network)System khud 3 baar retry karta hai, phir "pending uploads — Retry" button aata hai. Network aane pe Retry dabao — photo wapas nahi kheenchni padti.
